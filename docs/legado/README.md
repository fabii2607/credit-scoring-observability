# Capturas de uma execução anterior (14/10/2026)

As quatro imagens desta pasta foram capturadas em 14/10/2026, na entrega do
pacote 3, antes da integração final: mostram a versão anterior das regras de
alerta (8 regras) e um estado de falha do pipeline que não corresponde à
execução de referência de 21/10/2026. Ficam como registro histórico.

As evidências válidas da observabilidade estão em
[`docs/evidencias/observability/`](../evidencias/observability/README.md)
(verificação da stack e dos alertas recebidos). Recapturar as telas com a
stack atual (`make up-full` e o comando de referência de
[`delivery.md`](../delivery.md)) é uma ação proposta no
[post-mortem](../postmortem.md).
